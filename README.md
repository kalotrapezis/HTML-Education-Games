# 🎮 HTML Education Games

Συλλογή από αυτόνομα εκπαιδευτικά mini-παιχνίδια σε HTML/JavaScript για το Δημοτικό.
Κάθε παιχνίδι είναι **ένα μόνο αρχείο** που τρέχει σε οποιονδήποτε browser — δεν χρειάζεται
εγκατάσταση, build ή internet.

A collection of standalone HTML/JavaScript educational mini-games for primary school.
Each game is a **single file** that runs in any browser — no install, build step or internet required.

---

## ▶️ Πώς τρέχει / How to run

- **Απλό άνοιγμα:** κάνε διπλό κλικ σε οποιοδήποτε αρχείο `.html` (ή στο `παιχνίδια.html` για το μενού).
- **Με τοπικό server** (συνιστάται για το `milioner.html` και το `pixelart.html`, ώστε να φορτώνουν σωστά τα δεδομένα/εικόνες σε όλους τους browsers):

  ```bash
  python3 -m http.server 8000
  # μετά άνοιξε http://localhost:8000/παιχνίδια.html
  ```

## ✏️ Φτιάξε το δικό σου / Make it yours

### 1) Πρόσθεσε δικές σου ερωτήσεις στο quiz (`milioner.html`)

Κάθε μάθημα/τάξη είναι ένα αρχείο στον φάκελο `bank/`, π.χ. `bank/mathimatika-e.js`.
Η ονομασία είναι `{μάθημα}-{τάξη}.js` (τάξεις: `a b g d e st` = Α′ Β′ Γ′ Δ′ Ε′ ΣΤ′).

**Μορφή αρχείου bank:**

```js
window.registerQuiz({
  grade: "e",            // τάξη: a | b | g | d | e | st
  subject: "mathimatika",// μάθημα (πρέπει να υπάρχει στο manifest.js)
  chapters: [
    {
      id: "kefalaio-1",
      name: "Κεφάλαιο 1: Κλάσματα",
      questions: [
        {
          q: "Πόσο κάνει 1/2 + 1/2;",
          answers: ["1", "1/4", "2/4", "1/3"], // ΑΚΡΙΒΩΣ 4 απαντήσεις
          correct: 0,                            // δείκτης σωστής (0–3)
          d: "easy"                              // δυσκολία: easy | medium | hard
        }
        // ...βάλε 15+ ερωτήσεις ανά κεφάλαιο
      ]
    }
  ]
});
```

Το παιχνίδι **ανακατεύει** τις απαντήσεις στο runtime, οπότε η θέση της σωστής δεν έχει σημασία — αρκεί το `correct` να δείχνει τη σωστή.

**Για να φανεί το νέο αρχείο**, πρόσθεσε μία γραμμή στο `bank/manifest.js`:

```js
files: [
  // ...
  "mathimatika-e.js"   // ⬅️ πρόσθεσε εδώ το όνομα του αρχείου σου
]
```

Νέο **μάθημα**; Πρόσθεσέ το και στη λίστα `subjects` του `manifest.js`:

```js
subjects: [
  { id: "mathimatika", name: "Μαθηματικά", icon: "➗" }
  // { id: "to-diko-sou", name: "Το Μάθημά μου", icon: "📘" }
]
```

### 2) Πρόσθεσε σχέδια στο Pixel Art (`pixelart.html`)

Ρίξε την εικόνα σου στον φάκελο `presets/` και πρόσθεσε μία γραμμή στο `presets/manifest.js`:

```js
window.PRESETS_MANIFEST = [
  { name: 'Καρδιά', file: 'Heart.png' }
  // { name: 'Το σχέδιό μου', file: 'to-sxedio-mou.png' }
];
```

### 3) Πρόσθεσε ένα νέο παιχνίδι στο μενού

Φτιάξε το `.html` αρχείο σου και πρόσθεσε μια κάρτα (`<a class="card" href="...">`) μέσα στο `παιχνίδια.html`.
